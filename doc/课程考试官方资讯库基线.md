# 课程考试官方资讯库基线

> 基线日期：2026-08-30  
> 状态：首批官方来源与数据治理规范  
> 使用限制：本文件用于系统建模和后续录入，不代替考试局当年 syllabus/specification、信息手册、报名系统或学校考试官的最终确认。

## 1. 资讯库的职责

  本资讯库为 IG–A Level 一体化系统提供可追溯的课程、考试和制度依据。它不是普通文章库，也不把考试局宣传页当作足以执行报名的完整规则。任何会影响学生选课、考试报名、组件组合、成绩计算或重考的规则，都必须落到具体资格、科目代码、规范版本、考试系列和官方来源。

  系统需要同时保存两种规则：“考试局规则”说明资格如何授予，“学校规则”说明本校如何在九至十二年级组织教学。两者不得混在一个字段里。例如，学校可以把九年级设为加速 IG 阶段，但不能据此声称所有 IGCSE 都由考试局规定为一年制。

## 2. 已核对的基础事实

### 2.1 Cambridge International

| 主题 | 已核对事实 | 系统含义 | 官方来源 |
|---|---|---|---|
| 教育阶段 | Cambridge Upper Secondary 通常面向 14–16 岁，Cambridge Advanced 通常面向 16 岁以上 | 年龄是参考，不作为系统硬性报错；资格阶段与校内年级分开 | [Cambridge programmes and qualifications](https://www.cambridgeinternational.org/programmes-and-qualifications/) |
| IGCSE 周期 | Cambridge IGCSE 按 14–16 岁、两年课程设计，但允许用不同周期完成，也没有统一的正式年龄限制 | 九年级一年制或加速安排应标记为学校实施方案 | [Who can take Cambridge IGCSE?](https://help.cambridgeinternational.org/hc/en-gb/articles/203476042-Who-can-take-Cambridge-IGCSE) |
| IGCSE 评估 | 课程末评估可包含笔试、口试、coursework 和实践；部分科目区分 Core 与 Extended | 组件类型、路线和计分不能在资格层级写死，必须按科目规范保存 | [Cambridge IGCSE qualification](https://www.cambridgeinternational.org/programmes-and-qualifications/cambridge-upper-secondary/cambridge-igcse/qualification/) |
| Core/Extended | 仅部分科目提供；Core 与 Extended 的可获等级范围不同，学生不必所有科目选同一路线 | 选课/报名需保存每个学生每个科目的 entry route | [Core and Extended explained](https://help.cambridgeinternational.org/hc/en-gb/articles/203494082-What-is-the-difference-between-IGCSE-Core-and-Extended) |
| IGCSE 评分 | Cambridge IGCSE 全球常见 A*–G；部分代码提供 9–1，不能只凭科目名称判断 | `grading_scale` 绑定具体 syllabus code 和版本 | [Cambridge IGCSE grading choice](https://www.cambridgeinternational.org/programmes-and-qualifications/cambridge-upper-secondary/cambridge-igcse/grading-choice/) |
| IGCSE 考季 | 官方资格页说明 June 和 November 两个系列，通常分别在 August 和 January 放榜 | 考季模板按考试局生成，但具体科目可用性仍需当年 entry guide 确认 | [Cambridge IGCSE qualification](https://www.cambridgeinternational.org/programmes-and-qualifications/cambridge-upper-secondary/cambridge-igcse/qualification/) |
| AS/A Level 路径 | 可只考 AS、分阶段完成 A Level，或同一系列完成全部 A Level；AS 通常一年，A Level 通常两年 | 学生课程路径需保存 assessment route，不能假定所有科目都先 AS 后 A2 | [Cambridge AS & A Level qualification](https://www.cambridgeinternational.org/programmes-and-qualifications/cambridge-advanced/cambridge-international-as-and-a-levels/qualification/) |
| Carry forward | 分阶段路线通常要求符合科目规则；AS 成绩可在 13 个月范围内用于后续 A Level，且并非所有科目可用 | 系统按 source revision 计算到期提示，不把 13 个月规则套给不适用科目 | [What is a staged assessment?](https://help.cambridgeinternational.org/hc/en-gb/articles/29564157548434-What-is-a-staged-assessment) |
| AS/A 评分 | Cambridge AS 为 A–E，不设 A*；A Level 为 A*–E | 成绩枚举绑定资格层级 | [Cambridge AS & A Level qualification](https://www.cambridgeinternational.org/programmes-and-qualifications/cambridge-advanced/cambridge-international-as-and-a-levels/qualification/) |
| Syllabus 年份 | syllabus year 指学生参加考试的日历年 | 课程可以跨学年，但考试报名必须关联考试年份对应的 syllabus version | [Which syllabus year should I use?](https://help.cambridgeinternational.org/hc/en-gb/articles/37189948709522-General-FAQ-Which-syllabus-year-should-I-use) |
| 行政区与时间表 | Cambridge 中心属于不同 administrative zone，必须使用本中心对应的时间表；时间表仍可能修订 | 学校配置保存 zone；导入时间表时保存版本和检查日期 | [Cambridge exam timetables](https://www.cambridgeinternational.org/exam-administration/cambridge-exams-officers-guide/phase-1-preparation/timetabling-exams/exam-timetables/) |
| 考务周期 | 报名、coursework/样本、预测成绩、材料、考场和放榜均有独立活动与截止时间 | 考试管理不能只有一个 `registration_deadline` 字段，应保存多种 deadline event | [Cambridge Exams Officers’ Guide](https://www.cambridgeinternational.org/exam-administration/cambridge-exams-officers-guide/) |
| Access arrangements | 考前安排分组、申请方式和截止日期不同，目的是移除不必要障碍而不改变评估要求 | 单独建立保密、限权的申请记录与提醒；不得展示给无关教师 | [Cambridge access arrangements](https://www.cambridgeinternational.org/exam-administration/cambridge-exams-officers-guide/phase-1-preparation/access-arrangements/) |

### 2.2 Pearson Edexcel International

| 主题 | 已核对事实 | 系统含义 | 官方来源 |
|---|---|---|---|
| International GCSE 定位 | 面向 14–16 岁并用于衔接 A Level/IAL；采用 9–1 评分 | 资格阶段与校内年级分开；评分制按资格保存 | [About Pearson Edexcel International GCSEs](https://qualifications.pearson.com/en/qualifications/edexcel-international-gcses/about-international-gcses.html) |

| IAL 考季 | IAL 通常在 January、May–June 和 October 提供；部分科目或单元并非每个系列都有 | 选定考季时按当年 Information Manual 校验 unit availability | [Pearson International Advanced Levels](https://qualifications.pearson.com/en/qualifications/edexcel-international-advanced-levels.html) |
| Cash-in | 完成所需单元后，需要使用相应 cash-in code 请求资格成绩 | 系统要区分 unit entry 与 cash-in entry，并对缺失 cash-in 提醒 | [Pearson IAL results explained](https://qualifications.pearson.com/en/support/support-topics/results-certification/understanding-marks-and-grades/understanding-your-results-information-for-students/edexcel-international-advanced-level-results-explained.html) |
| UMS 与评分 | 单元给出 UMS 和单元等级；IAS cash-in 为 A–E，IAL cash-in 为 A*–E | 同时保存 raw mark、UMS、unit grade、qualification grade，禁止相互覆盖 | [Pearson IAL results explained](https://qualifications.pearson.com/en/support/support-topics/results-certification/understanding-marks-and-grades/understanding-your-results-information-for-students/edexcel-international-advanced-level-results-explained.html) |
| 重考聚合 | 2025/26 Information Manual 说明单元可重考，通常取最近两次非缺考中的较优成绩用于聚合，数学套件另有规则 | 重考规则必须按手册版本和科目例外计算，不能用一条全局“最高分”规则 | [Pearson IAL Information Manual 2025/26](https://qualifications.pearson.com/content/dam/pdf/Support/Information-manual/4-ial-2025-2026.pdf) |
| 时间表 | 官方考试时间表页面提供各资格、各系列的最终文件 | 导入文件时记录文件名、发布日期/版本、哈希和复核时间 | [Pearson exam timetables](https://qualifications.pearson.com/en/support/support-topics/exams/exam-timetables.html) |
| Access arrangements | 国际中心通过 Pearson Access Arrangements Online 处理相关申请 | 作为考试管理中的受限流程和截止提醒，不与普通学生备注混存 | [Pearson access arrangements](https://qualifications.pearson.com/en/support/support-topics/exams/special-requirements/access-arrangements.html/18072707) |

## 3. 当前不能写死的事项

- 九年级应该参加哪些 IG 科目、是否一年完成、是否在九年级参加正式考试，由学校课程方案和具体考试局规范共同决定。
- Cambridge IGCSE 是否使用 A*–G 或 9–1，必须依据具体 syllabus code、行政区和当年 entry guide。
- Cambridge 科目是否提供 Core/Extended、coursework、practical 或 carry forward，必须看具体 syllabus。
- Pearson International GCSE 是否采用模块化路径，必须看科目、首次教学/考试年份和中心资格。
- Pearson IAL 某个单元是否在 January、May–June 或 October 开考，必须看当年 Information Manual。
- 任何报名截止、结果日期、时间表、access arrangements 截止和费用都属于年度数据，不能复制上一年后继续使用。
- 成绩边界、raw-to-UMS 转换或组件阈值属于具体考试系列数据，不能作为永久常量。

## 4. 数据结构建议

### 4.1 `official_sources`

| 字段 | 类型建议 | 规则 |
|---|---|---|
| `id` | UUID | 主键 |
| `publisher` | enum/text | `cambridge`、`pearson`、监管/政府机构 |
| `source_type` | enum | qualification page、syllabus、handbook、information manual、timetable、policy |
| `title` | text | 官方标题 |
| `url` | text | 必须为允许域名的 HTTPS 地址 |
| `published_on` | date/null | 官方发布日期，未知时为空，不猜测 |
| `checked_at` | datetime | 最近人工核对时间 |
| `content_hash` | text/null | 对下载文件或受控快照计算 |
| `access_level` | enum | public、centre-only；中心受限材料不得公开 |
| `status` | enum | draft、verified、superseded、withdrawn |
| `verified_by` | user id/null | 与录入人分离 |
| `supersedes_id` | UUID/null | 指向上一版本 |

### 4.2 `qualification_specs`

| 字段 | 说明 |
|---|---|
| `board` | 考试局 |
| `qualification_level` | IG、International GCSE、IAS、AS、IAL、A Level |
| `subject_code` | 官方科目/规范代码 |
| `subject_name` | 官方名称及校内显示名称分开保存 |
| `version_label` | 如 `2027–2029 syllabus` 或 specification issue |
| `valid_exam_from/to` | 适用考试年份/系列 |
| `grading_scale` | A*–G、9–1、A–E、A*–E 等 |
| `assessment_model` | linear、modular、staged、subject-specific |
| `source_id` | 指向已验证来源 |
| `status` | draft、active、expired |

### 4.3 `qualification_components`

| 字段 | 说明 |
|---|---|
| `spec_id` | 资格规范 |
| `component_code` | paper/unit/component code |
| `component_name` | 官方名称 |
| `route_code` | Core、Extended、option、cash-in 等 |
| `required_kind` | required、choice、conditional |
| `weight/max_raw/max_ums` | 仅在来源明确时填写 |
| `available_series` | 不存永久 JSON；建议按年度拆到关联表 |
| `source_id` | 支撑该条事实的官方来源 |

### 4.4 `rule_revisions`

| 字段 | 说明 |
|---|---|
| `rule_type` | carry-forward、resit、cash-in、entry、access-arrangement 等 |
| `scope` | 考试局、资格、科目或组件 |
| `effective_from/to` | 生效范围 |
| `structured_value` | 机器可校验的有限 JSON；必须有 schema |
| `human_summary` | 给用户看的简短说明 |
| `source_id` | 官方依据 |
| `review_status` | draft、first-reviewed、verified、retired |

## 5. 官方来源白名单

| 发布者 | 允许域名 | 用途 |
|---|---|---|
| Cambridge International Education | `cambridgeinternational.org`、`help.cambridgeinternational.org` | 资格、syllabus、handbook、时间表、考务规则 |
| Pearson Qualifications | `qualifications.pearson.com` | specification、Information Manual、时间表、成绩与报名规则 |
| 中国人大网/国家法律法规数据库 | `npc.gov.cn`、`flk.npc.gov.cn` | 数据与个人信息相关法律 |
| 国家网信办 | `cac.gov.cn` | 个人信息、网络数据和合规审计规则 |

  允许域名不等于页面自动可信。新闻、历史手册、旧 specification 和当前规则页面必须按发布日期、生效年份和状态区分。学校支持门户中的受限文件只能记录元数据和校内访问指引，不能复制到学生可访问的公开路径。

## 6. 更新与复核流程

1. 录入人员从官方目录定位当年文件，记录 URL、标题、发布/检查时间和适用范围。
2. 对下载的 PDF/XLSX 计算哈希；网页记录必要的受控快照信息，但不整页公开复制。
3. 将自然语言规则拆为结构化字段和人类摘要，无法确定时保留 `unknown`，不得猜值。
4. 第二名具备考试业务职责的人员对照官方原文复核科目代码、组件、考季和例外。
5. 通过复核后才把状态改为 `verified`；系统规则只读取已验证且当前生效的记录。
6. 新版本发布时新增记录并关联 `supersedes_id`，不覆盖旧记录。
7. 变更影响已有学生时生成影响清单：学生、科目、计划考季、旧规则、新规则和待处理人。
8. 报名完成后冻结该次报名所引用的规则版本，后续网页更新不追溯改变已完成记录。

## 7. 复核节奏

| 时间点 | 必查内容 |
|---|---|
| 每季度 | 资格目录、syllabus/specification 更新、制度公告 |
| 新学年课程发布前 | 学校开设科目、版本、评分制、教学周期、先修与考试路径 |
| 每个考季开放前 | 科目/单元可用性、entry/cash-in/option code、截止日期、费用节点 |
| 最终时间表发布后 | 日期、session、时区/行政区、版本修订、考场冲突 |
| 报名前 | 候选人身份、组件组合、Core/Extended、cash-in/carry forward、特殊安排 |
| 放榜前后 | 结果发布日期、成绩边界、成绩服务、复核/申诉时间窗口 |

## 8. 首批录入顺序

  首批不应一次录入所有官方科目。先由学校提交当前实际开设清单，再按以下顺序建立可用数据：

1. 学校当前考试局与中心行政配置。
2. 九年级首批 IG 科目及其当前规范版本。
3. 十至十二年级现有 IAL/A Level 科目、单元、cash-in 或 staged route。
4. 当前学年和下一学年的考试系列、报名节点和最终时间表。
5. 重考、carry forward、cash-in、Core/Extended 与 access arrangements 等会影响学生决策的制度。
6. 教学建议、先修关系和校内升段要求；此类记录标记为 `school_policy`，不混入官方规则。

```yaml
component_or_unit_rules: []
series_availability: []
special_rules: []
official_source:
  title: ""
  url: "https://..."
  published_on: null
  checked_at: "YYYY-MM-DDTHH:mm:ssZ"
  content_hash: null
review:
  entered_by: ""
  verified_by: ""
  status: draft

```

  YAML 仅作为人工准备模板；正式实现应通过后台表单和服务端 schema 校验写入数据库。`unknown` 与空值必须区分：未知表示已检查但尚不能确认，空值表示尚未录入。

# 数据口径：入学年份、预毕业与学制联动（BIZ-01～03）

与 `doc/修改需求-开发任务清单.md` 第一节一致，供前后端与展示统一引用。

## BIZ-01 年级 = 入学年份

- **主数据**：学生表 `enrollment_year` 为四位整数（如 `2024`）。
- **界面**：「2024级」与数字 **同一字段两种展示**，不维护第二套年级字段。
- **筛选**：课程 `grade_level` 为 `ALL` 或 **等于** 该入学年份字符串/数字口径（与 `courseVisibleForStudent` 一致）。

## BIZ-02 预毕业时间

- **字段**：`expected_graduation_month`，格式 **YYYY-MM**。
- **学制**：`study_duration` 为 `2` 或 `3`（年制），与预毕业月共同约束展示与推算。

## BIZ-03 学制切换后的联动范围（已确认）

- **会更新**：预毕业年月（及依赖它的年级/届别相关 **展示与筛选**）。
- **不自动改动**：已录入的 **考试日期**、待办 **deadline**（不因学制切换做平移或批量重算）。

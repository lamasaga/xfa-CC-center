# A-Level升学指导中心 - 学生管理系统

## 项目概述

一个基于 React + TypeScript + Vite 开发的 A-Level 升学指导中心学生管理系统，用于管理学生信息、成绩、目标院校、考试安排等升学相关数据。

**技术栈:**
- **前端:** React 19 + TypeScript + Vite 7 + Tailwind CSS 3.4 + shadcn/ui
- **后端:** Node.js + Express + SQLite (better-sqlite3)
- **数据库:** SQLite (单文件数据库，零配置)
- **构建工具:** Vite
- **样式方案:** Tailwind CSS + CSS Variables

## 核心功能模块

### 1. 认证与权限
- **登录系统:** JWT Token 认证
- **角色权限:** admin / editor / viewer 三级权限
- **测试账号:**
  - admin / admin123
  - editor / editor123
  - viewer / viewer123

### 2. 仪表盘视图 (Dashboard)
- 学生选择器（支持切换查看不同学生）
- 关键指标概览 (KeyMetricsPanel)
- 学生能力雷达图 (StudentRadarChart)
- 成绩对比分析 (GradeComparisonPanel)
- 院校匹配度 (UniversityMatchPanel)
- 优先任务列表 (PriorityTasksPanel)
- 快捷操作面板 (QuickActionsPanel)

### 3. 学生管理
- **学生列表:** 查看、搜索、筛选、刷新
- **添加学生:** 填写基本信息、年级、联系方式
- **学生详情:** 编辑信息、管理成绩、查看目标院校
- **年级系统:** 按入学年份（如 2024级、2025级）

### 4. 课程与成绩
- 课程列表查看
- 学生成绩录入与修改
- 单元成绩管理

### 5. 目标院校
- 院校库管理
- 学生目标院校添加
- 申请状态跟踪

## 开发指南

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
# 同时启动前端和后端
npm start

# 或分别启动
npm run server    # 启动后端 (port 3001)
npm run dev       # 启动前端 (port 5173)
```

### 数据库初始化
```bash
# 初始化 SQLite 数据库并迁移数据
node server/init-db.js
node server/migrate-data.js
```

### 构建项目
```bash
npm run build
```

## 已知问题与待修复项

### 🔴 高优先级问题

1. **学生列表无法显示**
   - 现象：学生管理页面显示"暂无学生数据"，API返回空数组
   - 排查：后端数据库查询正常，问题可能在API路由的数据组装阶段
   - 状态：待修复

2. **Token过期导致的数据加载失败**
   - 现象：控制台显示 `Fetched students: 0`，后端返回 401/403
   - 临时解决：退出登录后重新登录
   - 永久解决：需要完善token自动刷新机制
   - 状态：待修复

### 🟡 中优先级问题

3. **NaN警告**
   - 现象：控制台显示 `Received NaN for the children attribute`
   - 位置：`GoalsAndActions.tsx` 中的匹配度计算
   - 状态：已部分修复，需验证

4. **Dialog组件警告**
   - 现象：`Warning: Missing Description or aria-describedby for DialogContent`
   - 影响：不影响功能，但影响无障碍访问
   - 状态：待优化

6. **学生详情页面功能完善**
